# Personal Dotfiles

This is my personal repository containing **dotfiles**, including:

- My personal **Neovim configuration**
- My custom **Git aliases**
- Other personal configuration files

---

## Neovim Configuration

To apply the Neovim configuration on your system, simply run the setup script:

```bash
./scripts/vim-autosetup.sh
```

## GIT aliases configuration

To apply the Git configuration on your system, simply run the setup script:

```bash
./scripts/gitconfig-setup.sh
```
